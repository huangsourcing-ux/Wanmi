# 专题内容模板

适用于榜单、报告、系列内容和赞助栏目。专题必须说明范围、方法、版本和更新周期，不能把赞助关系包装成自然排序。

## 后台字段填写

| 字段              | 填写要求                                                    |
| ----------------- | ----------------------------------------------------------- |
| `title`           | `【专题主题】｜【版本、年份或适用范围】`                    |
| `slug`            | `【stable-topic-slug】`；只有真正按年独立存档时才包含年份。 |
| `summary`         | `【专题回答什么、覆盖哪些对象、采用什么口径】`              |
| `relatedTools`    | `【选择专题章节实际使用的工具】`                            |
| `relatedTldPages` | `【选择专题覆盖且已发布的 TLD 页面】`                       |
| `source`          | 按[统一来源格式](README.md#统一来源格式)填写，发布前必填。  |
| `meta.*`          | 按[统一 SEO 规范](README.md#统一-seo-规范)填写并确认。      |

## 正文模板

```text
【如为赞助专题，第一段显著写：赞助专题｜赞助方：【主体】｜赞助影响范围：【资金/素材/无编辑干预等事实说明】】

专题负责人：【姓名/团队】
编辑：【姓名】
当前版本：【版本号或 YYYY-MM-DD】
最后事实核验：【YYYY-MM-DD】
计划复核：【频率或下一日期】

【专题导语：说明目标读者、核心问题、覆盖范围和不覆盖范围。】

## 阅读导航

- 【章节一：解决的问题】
- 【章节二：解决的问题】
- 【章节三：解决的问题】

## 范围与方法

- 样本/对象：【纳入和排除条件】
- 数据区间：【起止日期或快照时间】
- 数据来源：【主要一手来源】
- 判断方法：【排序、比较或分析规则】
- 局限：【样本、时效、provider、商业关系或无法验证项】

## 【章节一标题】

【先给结论，再给证据、适用条件和限制。】

## 【章节二标题】

【使用相同口径；不要在不同章节悄悄改变指标定义。】

## 【章节三标题】

【说明读者可以采取的下一步，并关联相关工具/TLD。】

## 商业关系与编辑独立性

【无赞助则写“本专题无赞助关系”；有赞助则列赞助方、合作范围、审核责任及是否影响选题/排序。】

## 来源与授权

- 【机构/作者】，《【标题】》，【URL】，访问日期：【YYYY-MM-DD】，用途：【数据/方法/定义】
- 【图片/图表来源与授权编号】
- 授权/引用说明：【原创、合理引用、公开许可、转载授权或赞助关系】

## 版本与修订记录

- 【版本/日期】：【负责人】｜【范围、方法或结论变化】｜依据：【来源或原因】
```

## SEO 与来源检查

- SEO 标题明确专题主题和当前适用范围；描述包含方法或关键局限，不使用夸大排名词。
- OG 图片为已审核站内 Media，不使用无法证明来源的图表或品牌素材。
- canonical 默认留空；只有重复版本合并时指向确定的主版本。被 canonical 到别页的当前专题不会进入 sitemap。
- `source` 与“来源与授权”一致；赞助方和影响范围同时出现在首段与商业关系章节。

## 提交审核前检查

- [ ] 所有占位符已清除，阅读导航和实际章节一致。
- [ ] 范围、样本、方法、数据时间和局限可复核。
- [ ] 榜单/比较使用同一口径，赞助不影响或不隐藏排序规则。
- [ ] 相关工具和 TLD 均与对应章节相关且公开可用。
- [ ] 私有预览已检查长页面导航、表述、图片、商业标识和移动端布局。
