# TLD 页面内容模板

适用于 `/tld/{tld}` 后缀页面。页面负责解释用途、规则、价格来源和相关工具，不得把缓存价格写成保证成交的长期报价。

## 后台字段填写

| 字段           | 填写要求                                                                                                      |
| -------------- | ------------------------------------------------------------------------------------------------------------- |
| `title`        | `.【后缀】域名｜【主要用途或定位】`                                                                           |
| `slug`         | `【tld-without-leading-dot】`；小写 ASCII，不带前导点。                                                       |
| `summary`      | `【后缀用途、适合对象、关键注册限制和价格时效提示】`                                                          |
| `relatedTools` | 至少核对域名查询、WHOIS/RDAP、DNS/NS、价格、IDN、SSL/CAA 中真正适用的工具。                                   |
| `source`       | 按[统一来源格式](README.md#统一来源格式)填写；规则和价格应优先采用注册局、ICANN/权威目录及项目批准 provider。 |
| `meta.*`       | 按[统一 SEO 规范](README.md#统一-seo-规范)填写并确认。                                                        |

TLD 页面没有可手工填写的 `relatedTldPages`；文章、专题和帮助页关联当前 TLD 后，相关内容会通过反向关系自动展示。

## 正文模板

```text
页面负责人：【姓名/团队】
编辑：【姓名】
规则核验：【YYYY-MM-DD】
价格核验：【YYYY-MM-DD HH:mm，时区】

【导语：解释该后缀是什么、典型用途，以及价格/可注册性以实时查询为准。】

## 后缀概览

- 后缀：.【TLD】
- 注册局/管理机构：【权威主体】
- 主要用途：【通用、地区、行业等事实】
- 支持 IDN：【是/否/待确认；列适用语言或限制】
- 数据更新时间：【YYYY-MM-DD】

## 适合谁使用

- 【场景一及理由】
- 【场景二及理由】
- 不适合或需谨慎：【商标、地域、资质、兼容性等限制】

## 注册与实名规则

- 注册资格：【个人/组织/地域/行业限制】
- 实名要求：【已核验规则；不确定时明确写待确认】
- 名称长度与字符：【规则和 IDN/Punycode 提示】
- 保留词/溢价域名：【是否存在及查询方式】
- 其他限制：【注册局或 provider 明示要求】

## 价格与期限

- 展示币种和单位：【人民币/元；按年等】
- 新注册：【只说明页面动态价格的读取位置，不手写长期固定值】
- 续费：【只说明页面动态价格的读取位置，不把注册价等同续费价】
- 期限：【支持年限；以实时报价和订单确认页为准】
- 数据来源：【批准 provider/价格快照】
- 时效说明：【价格、汇率、溢价和活动可能变化；最终以服务端有效报价为准】

## 生命周期与到期注意事项

【说明注册、续费、到期、赎回/删除等已核验规则；无法确认的阶段不得推断。P1 不承诺默认自动续费。】

## 查询与技术检查

1. 【通过相关域名查询工具检查可注册状态】
2. 【通过 WHOIS/RDAP 查看公开注册信息及缺失限制】
3. 【通过 DNS/NS、IDN 或 SSL/CAA 工具完成适用检查】

## 风险与限制

- 【规则和价格的时间边界】
- 【商标、合规、注册局或 provider 限制】
- 【查询结果不等于最终注册成功的原因】

## 来源与授权

- 【注册局/ICANN/权威目录】，《【页面或规则名称】》，【URL】，访问日期：【YYYY-MM-DD】
- 【批准 provider】，【价格/可注册信息名称】，快照时间：【YYYY-MM-DD HH:mm，时区】
- 【图片来源与授权编号】

## 修订记录

- 【YYYY-MM-DD】：【负责人】｜【规则、价格口径或说明变化】｜依据：【来源】
```

## SEO 与来源检查

- SEO 标题包含规范后缀和主要意图；描述同时包含用途、关键限制和实时价格提示。
- OG 图片不得仿冒注册局或 provider 官方背书，素材来源和授权必须明确。
- canonical 默认留空；`noIndex` 默认关闭。不要把不同 TLD 页面 canonical 到同一通用页面来替代独立说明。
- `source` 与正文权威来源一致；价格、规则、实名和生命周期结论都有核验日期。

## 提交审核前检查

- [ ] 后缀、注册局、用途、字符、IDN、资格和实名规则均有依据。
- [ ] 价格按动态数据描述，注册价与续费价不混淆，未承诺默认自动续费。
- [ ] 相关工具可用且页面不依赖未发布内容解释核心规则。
- [ ] 不把“查询可用”表述为“保证注册成功”。
- [ ] 私有预览已检查小数点、币种、日期、链接、图片和相关内容区域。
