# 帮助页内容模板

适用于数据来源、术语解释、工具使用说明和故障处理。帮助页要让用户明确知道前置条件、操作结果、限制和安全边界。

## 后台字段填写

| 字段              | 填写要求                                                                             |
| ----------------- | ------------------------------------------------------------------------------------ |
| `title`           | `如何【完成任务】`、`【术语】是什么意思`或`【问题】处理方法`                         |
| `slug`            | `【task-or-term-slug】`；保持稳定，不使用工单号或临时日期。                          |
| `summary`         | `【说明适用场景、用户完成后得到什么，以及一个关键限制】`                             |
| `relatedTools`    | `【选择步骤中实际使用的工具】`                                                       |
| `relatedTldPages` | `【只在帮助内容与特定已发布后缀直接相关时选择】`                                     |
| `source`          | 按[统一来源格式](README.md#统一来源格式)填写；操作说明也必须标明内部核验或外部依据。 |
| `meta.*`          | 按[统一 SEO 规范](README.md#统一-seo-规范)填写并确认。                               |

## 正文模板

```text

适用版本/环境：【Web/P1/浏览器或功能版本】
最后验证：【YYYY-MM-DD】

【用一段话说明问题、适用对象和预计结果。不要承诺无法保证的处理时间或结果。】

## 开始前确认

- 【所需账号、权限或是否无需登录】
- 【需要准备的数据，但不得要求用户提交 OTP、Cookie、私钥、支付凭据或证件原件】

## 操作步骤

## 预期结果

- 成功：【用户看到什么、数据来源和时间在哪里】
- 部分成功/过期：【哪些结果仍可用，哪些需要重试】
- 限流：【如何等待和安全重试】
- 不可用：【如何识别降级，不把未知状态包装成确定结果】

## 常见问题与处理

### 【错误或现象一】

- 原因：【可验证原因】
- 处理：【安全步骤】
- 不要做：【可能扩大影响的操作】

### 【错误或现象二】

- 原因：【可验证原因】
- 处理：【安全步骤】
- 升级条件：【何时停止重试并提交反馈/联系支持】

## 安全、隐私与限制

- 【数据是否发送到服务端、是否保存、保存时长或仅本地处理】

## 仍未解决时

【指向站内反馈/联系入口；要求提供 traceId、发生时间、页面路径和脱敏现象，不要求提交秘密或完整证件/域名查询内容。】

## 来源与授权

- 【产品内部验证/权威文档】，《【标题】》，【URL 或受控文档标识】，验证日期：【YYYY-MM-DD】
- 【图片来源与授权编号】

## 修订记录

- 【YYYY-MM-DD】：【维护人】｜【步骤、状态或限制变化】｜依据：【测试/文档/事件】
```

## SEO 与来源检查

- SEO 标题直接使用用户任务或错误现象；描述说明解决目标、适用环境和关键限制。
- OG 图片只用于确实能帮助识别步骤的场景；截图必须脱敏，Media 来源和审核完整。
- canonical 默认留空；`noIndex` 默认关闭。仅内部性很强但仍需公开访问的帮助页才考虑 `noIndex`。
- `source` 与实际验证环境和权威文档一致；过时步骤不得只改日期而不重新验证。

## 提交审核前检查

- [ ] 已按普通用户权限复走全部步骤，成功、错误、限流和降级状态描述准确。
- [ ] 示例、截图和链接不含手机号、Cookie、OTP、证件、密钥、支付信息或完整查询域名。
- [ ] 数据来源、缓存/时效和不确定性在结果附近说明。
- [ ] 相关工具/TLD 与步骤一致，反馈升级条件明确。
- [ ] 私有预览已检查标题层级、编号连续性、截图可读性和移动端布局。
