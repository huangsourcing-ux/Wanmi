## 3. Migration 升级、回滚与约束（41/41）

每个迁移变异只运行聚焦 verifier。verifier 在边界明确的临时本地数据库建立 D9-D-1 前置最小 schema，
执行真实 UP，行为断言 enum、列、非空、外键、唯一约束、索引、默认值及无效写入拒绝；随后插入 DNS
provider operation，执行真实 DOWN，断言只删除本切片 schema 和 DNS operation、精确恢复旧 enum，
最后再次 UP 验证往返。数据库名与删除目标均由 verifier 精确校验；全部使用本地 fixture schema。
