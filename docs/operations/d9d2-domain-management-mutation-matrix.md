## 4. A4 风险表逐项自查

| 本切片操作         | 风险表档位                       | 实现与结论                                                                                                                                                                                                 |
| ------------------ | -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 获取域名管理密码   | step-up + 绑定渠道确认           | `domain_management_password` grant 通过且 A5 冷静期 inactive 后，要求至少一个当前 active 绑定渠道；读取成功后复用 A2 通知路径向全部 active provider 告知并逐渠道留 outcome。通知投递失败不回滚已完成读取。 |
| 修改域名管理密码   | step-up + 绑定渠道确认           | 与读取使用相同 purpose/冷静期/active 渠道判定；上游写仍走 D6-01，完成后逐渠道告知。明文只存在请求和单次 provider 调用，不落 operation key、事件、审计或日志。                                              |
| 修改域名联系人信息 | step-up + 二次确认               | 使用 `realname_change` grant（因此继承 A5 冷静期）并要求 `confirmed === true`；只接受本人已审核模板资料和文档四种 `eppidtype`。                                                                            |
| 模板过户           | step-up + 二次确认               | 与联系人修改同档；目标必须属于当前 customer，且本地状态、上游审核状态、确认时间和纯数字上游模板 ID 同时有效。                                                                                              |
| 域名证书下载       | 当前会话 + 审计                  | 风险表未将只读证书列为 step-up；使用 A3、本人资产与失败关闭上游归属检查，追加 requested/confirmed/failed 审计，响应 `no-store`。                                                                           |
| 用户主动同步       | 当前会话 + 审计                  | 只查询上游并追加观察；差异进入 pending，不覆盖本地事实。归属 unknown/not-owned 均标记阻断。                                                                                                                |
| 后台全量同步       | 无人值守系统任务，不依赖 step-up | 仅无 user principal、background 独占、零自动重试；它不执行 provider 写，不混用交互式 grant。                                                                                                               |
| 能力声明           | 当前会话                         | 先校验本人资产，再返回显式能力表；不执行上游写。                                                                                                                                                           |

DNS 添加/修改/删除/暂停入口也自动受同一 not-owned/unknown 阻断。批量与离线任务、DNSSEC、DDNS、
常用邮箱解析、域名转入/转出均未实现或留桩。
