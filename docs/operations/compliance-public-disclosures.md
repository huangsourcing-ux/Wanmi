# 公开合规展示配置

## 适用范围

本记录说明 D8-01 的公开备案、临时上线声明和域名注册服务机构披露如何配置。它只提供代码层实现前置，不代表开发计划 11.3 的外部专业复核、公安联网备案、六类法务文档审核或最终上线批准已经完成。

配置复用 Payload `siteSettings` 的既有 key/value 结构，不新增字段或 migration。只有 `system_admin` 可以创建、更新或删除该 Collection 的记录；公开页面使用 `overrideAccess: false` 读取。

## 配置键与结构

key 固定为：

```text
compliance.public-disclosures.v1
```

2026-08-12 已通过的 ICP 备案和当前批准的实际域名注册服务机构可由 `system_admin` 写为：

```json
{
  "schemaVersion": 1,
  "icpRegistrationNumber": "渝ICP备18017546-13",
  "registrarName": "西部数码",
  "showPrelaunchNotice": true
}
```

`showPrelaunchNotice` 控制“生产服务上线前仍需完成……”临时声明。负责人明确决定撤下后才可设为 `false`；切换该值不改变任何上线门槛状态。

公安联网备案尚未完成，因此当前配置不得包含 `publicSecurityRegistration`。完成后由负责人核对真实号码和公安备案详情 URL，再成对加入：

```json
{
  "publicSecurityRegistration": {
    "number": "<经确认的公安联网备案号>",
    "url": "https://www.beian.gov.cn/portal/registerSystemInfo?recordcode=<经确认的编号>"
  }
}
```

该片段需要与其余必填字段合并为一个完整 value，不能单独保存。URL 只接受 HTTPS `www.beian.gov.cn/portal/registerSystemInfo` 详情页。

## 失败与未配置行为

- 未建立配置或 value 不符合完整 schema 时，页面不显示 ICP 号、公安联网备案号或域名注册服务机构，不生成任何占位或推测值；
- ICP 链接固定指向工信部备案系统 `https://beian.miit.gov.cn/`，显示文本只取配置值；
- 公安联网备案号和链接必须同时存在并通过官方域名校验，否则整份配置 fail-closed；
- 临时声明在配置缺失或无效时默认继续显示，避免未经负责人决定自动撤下；
- 配置可用时，注册服务机构披露出现在页脚、定价页、支付/下单页和域名资产详情页，责任边界统一链接到 `/legal/terms`。

## 上线前人工核对

1. 负责人通过 Payload Admin 以 `system_admin` 写入完整配置，并记录变更审计/工单证据；
2. 匿名访问首页与定价页，核对 ICP 文本和工信部链接，确认未出现公安备案占位；
3. 使用测试客户进入支付页和本人域名资产详情页，核对四处机构名称一致、责任边界链接正确；
4. 负责人决定是否关闭临时上线声明；
5. 外部法务完成责任边界及六类法务文档审核后，由负责人单独更新开发计划 11.3；本实现不得代替或提前勾选该门槛。
