## 4. 指定跨切片与边界用例

- 跨用户：`keeps list, search, filters and mixed-owner batch preferences isolated to the authenticated owner`；
  `uses the access-controlled Local API source and explicit owner predicates for list and batch reads`。
- 超过 10 条：`returns and updates every one of more than ten explicitly selected owner assets`，直接断言
  列表 12 条、total 12、分页 5/5/2，以及批量 12 条事实和 12 条限定 owner/batch 的追加事件。
- 关闭锁：`rejects disabling the domain lock without step-up and notifies every active provider after success`，
  缺 step-up 拒绝，成功后逐 provider 保存 outcome；冷静期由
  `rejects domain unlock during the A5 identity-risk cooldown even with a valid grant` 独立保护。
- 开启锁：`enables the domain lock with the current session and audit but no step-up or bound channel`，不创建
  step-up 即成功，通知为 0，requested/outcome 事件及审计各 2 条。
- 最后提醒档：`cannot disable the final reminder tier and the existing reminder chain honors valid channel preferences`。
- D9-D-2 回归：`blocks lock changes through D6-01 when the asset is not in the current upstream account`，确认
  provider 锁写为 0 次。

所有西部数码调用均使用 fixture；完整变异期间 `ALLOW_REAL_WESTDIGITAL*` 与通用真实 provider 写闸门
保持 false，没有真实域名、资金、短信或生产写入。
